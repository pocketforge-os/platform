# Synthetic clamshell fixture

A SYNTHETIC two-screen clamshell (tsp-h5ed.46.3): test data for the descriptor v2 articulation
rules, not a device. It lives outside `devices/`, so it is never in `ci-matrix.toml`, `pf build`
or the catalog. See `docs/CAPABILITIES-SCHEMA.md` (Reference fixture).

- `devices/synth-clamshell/capabilities.toml`, `profile.toml`: hand-authored.
- `skins/synth-clamshell/body.png`, `body_lit.png`, `model.glb`: generated by `gen_fixture.py`
  (stdlib only, deterministic). `gen_fixture.py --check` is the drift gate.

```
python3 tests/caps-fixtures/clamshell/gen_fixture.py --check
python3 core/caps.py --root tests/caps-fixtures/clamshell validate
```

## glb convention

`model.glb` follows the same convention as a real exported package; `device-models/export_gltf.py`
is the authority, and this fixture copies it rather than defining its own:

- frame `pf-mm-v1` (X left->right, Y bottom->top, Z rear->front), node names `pf-semantic-v1`;
- units glTF metres: pf-mm-v1 millimetres x 0.001 (`export_gltf.MM_TO_M`), float32-rounded;
- `asset.extras` declares `frame`, `units` and `naming` with the exporter's exact strings, plus
  `model` and `source` (this generator).

`regression/caps/test_caps_v2.py` compares those three keys against the committed
`skins/a133/model.glb` export and checks the base box and the `pivot_lid` hinge are in metres.
If the exporter's convention changes, change `gen_fixture.py` to match and regenerate.
